# Invoice Generator

A simple, installable web app for creating and saving invoices — built for freelance/design work.

## Features
- Add line items (description, qty, price) with automatic totals
- Optional VAT (7.5%) and flat discount
- Save your business info once — auto-fills every invoice header
- Save invoices for later, copy as text (for WhatsApp), or print/save as PDF
- Installable as an offline app on phone and laptop (PWA)

## Files
- `index.html` — the app
- `manifest.json`, `sw.js` — PWA install + offline support
- `icon.svg`, `icon-192.png`, `icon-512.png` — app icons

## Deploy
Same as your other apps: create a new GitHub repo, upload these files, enable GitHub Pages (Settings → Pages → Deploy from branch → main → root).
